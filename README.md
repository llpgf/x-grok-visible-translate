# X Grok 自動翻譯

只翻譯進入視窗、且不屬於 X 目前介面語言的貼文。目標語言跟隨 X 的介面語言；繁中介面會使用繁中。

原生「顯示翻譯」存在時，腳本保留並點擊該控制項。原生控制項未下發時，腳本才呼叫 X 的 Grok 翻譯端點，將貼文原文直接替換；可在同一位置切回原文。

## 安裝

在支援 userscript 的瀏覽器擴充功能中安裝 [腳本](https://raw.githubusercontent.com/llpgf/x-grok-visible-translate/main/x-grok-visible-translate.user.js)。

## 注意

此腳本依賴非公開 X 端點。X 改版、帳號資格或限流時可能失效。
